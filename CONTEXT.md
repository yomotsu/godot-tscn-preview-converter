# Godot TSCN Preview & Three.js Converter

This context defines the terms used for the browser service that previews Godot scenes and converts them for Three.js.

## Language

**Service**: A browser-based tool for previewing Godot `.tscn` scenes and exporting them as Three.js scene data or reusable class code.
_Avoid_: TSCN Loader

**Preview**: An interactive Three.js rendering of a Godot scene in the browser.
_Avoid_: Scene viewer
